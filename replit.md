# Isabella Vasques Portfolio

A root-level, static Jekyll site intended for GitHub Pages at `isabellavsqs.github.io`.

## Source of truth

- Page copy and YAML front matter: `index.md`, `about.md`, `work-experience.md`, and `contact.md`
- Shared layout and metadata: `_layouts/` and `_includes/`
- Styling and favicon: `assets/css/site.css` and `favicon.svg`
- GitHub Pages settings and local instructions: `_config.yml` and `README.md`

Keep the project static: no application framework, backend, database, contact form, or third-party trackers. The public contact method is LinkedIn only.
